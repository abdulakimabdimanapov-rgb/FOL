### 1.1 Как это работает

**Принцип:** Весь интеллект на MacBook. Телефон — только интерфейс.

1. **Samsung A16** подключается к Mac через USB
2. **Chrome Remote Debugging** через ADB (Android Debug Bridge)
3. FOL на MacBook открывает Chrome DevTools к телефону
4. Через CDP (Chrome DevTools Protocol) FOL управляет браузером на телефоне
5. Результаты сохраняются в Obsidian vault (синхронизируется через iCloud/Obsidian Sync)

### 1.2 Настройка (один раз)

```bash
# 1. Установить Android Platform Tools
brew install --cask android-platform-tools

# 2. На телефоне: Settings → Developer Options → USB Debugging → ON
# 3. Подключить телефон по USB → Разрешить отладку

# 4. Проверить подключение
adb devices
# → List of devices attached
# → XXXXXXXXXXXXXXXXX    device

# 5. Forward Chrome DevTools порт
adb forward tcp:9222 localabstract:chrome_devtools_remote

# 6. Открыть в Chrome на Mac
# chrome://inspect/#devices
# → Виден Samsung A16 с открытыми вкладками
```

## 2. ДВА РЕЖИМА РАБОТЫ

### 2.1 USB-режим (основной)

Телефон подключён к Mac через USB.

```
Samsung A16 (USB) ─► ADB ─► Chrome CDP :9222 ─► FOL Agent Server
```

**Что можно делать:**
- Открывать URL на телефоне
- Читать содержимое страниц
- Извлекать полезную информацию
- Сохранять в Obsidian (на Mac, синхронизируется на телефон)

**Ограничения:**
- Телефон должен быть подключён к Mac
- Только браузер (Chrome/Samsung Internet)
- Нельзя управлять другими приложениями на телефоне

### 2.2 Remote-режим (будущее)

Телефон подключён через интернет (Wi-Fi/5G).

```
Samsung A16 ─► Bridge Server (WebSocket) ─► MacBook FOL
```

**Что нужно разработать:**
- WebSocket сервер на Mac (bridge)
- Клиентское приложение на телефоне (FOL Lite — PWA или WebView)
- Шифрование (TLS)
- Push-уведомления

## 3. DAILY OBSIDIAN NOTES

Каждый день FOL автоматически:

1. **Создаёт** ежедневную заметку в Obsidian: `Daily/2026-04-12.md`
2. **Записывает** что пользователь делал (из daily_tracker)
3. **Сохраняет** изученное из интернета в `Knowledge/`
4. **Линкует** с проектами и идеями

### 3.1 Формат ежедневной заметки

```markdown
---
created: 2026-04-12T00:00:00Z
tags: [daily, fol]

## 📱 Activity Timeline
- 09:15 — Using VS Code (FOL project)

- 14:00 — Learning: Obsidian Local REST API setup

## 📚 Learned Today
- [[Knowledge/obsidian-local-rest-api]] — How to connect Python to Obsidian
- [[Knowledge/android-chrome-remote-debugging]] — ADB + CDP setup

## 🎯 Goals
- [x] Set up Obsidian bridge
- [ ] Test Samsung phone connection
- [ ] Write daily summary logic

## 📝 Notes
- Discovered that Samsung Internet supports CDP the same as Chrome
- Need to test with multiple tabs

## 🔗 Links
- [[Projects/FOL/obsidian-memory]]
- [[Projects/FOL/phone-bridge]]
```

### 3.2 Создание ежедневной заметки

```python
# Псевдокод для создания ежедневной заметки

from obsidian.client import write_note, patch_note
from utils.daily_tracker import get_today_summary

async def create_daily_obsidian_note():
    date = datetime.now().strftime("%Y-%m-%d")
    weekday = datetime.now().strftime("%A")
    
    vault_path = f"Daily/{date}"
    summary = get_today_summary()
    
    content = f"""# {date} — {weekday}

## Activity Timeline
{summary}

---
*Auto-generated by FOL. Edit in Obsidian.*
"""
    
    try:
        result = write_note(vault_path, content)
        print(f"Daily note created: {vault_path}")
        return result
    except ObsidianNotFoundError:
        print("Obsidian not connected — logged to episodic instead")
        from utils.episodic_writer import append_event
        append_event(
            summary=f"Daily note would be: {summary[:200]}",
            category="daily",
            source="daily_tracker",
        )
```

## 4. WEB LEARNING FLOW

Как FOL учится из интернета и сохраняет в Obsidian:

```
1. Пользователь говорит: "Научись чему-нибудь полезному"
   └► LLM вызывает learn_from_web(topic="...")

2. FOL ищет в интернете (Tavily search)
   └► 3 запроса: topic, topic + key concepts, topic + best practices

3. LLM анализирует результаты
   └► Извлекает ключевые инсайты
   └► Форматирует как markdown

4. FOL сохраняет в Obsidian
   └► Knowledge/{topic-slug}.md
   └► Автоматические ссылки на связанные заметки

5. FOL логирует в daily activity
   └► "Learned about: {topic}"
   └► Обновляет ежедневную заметку
```

### 4.1 Команды для пользователя

```
"Научись чему-нибудь полезному про AI agents"
  → learn_from_web("AI agents architecture", depth="deep")

"Сохрани это в Obsidian"
  → save_to_obsidian(folder="Knowledge", title="...", content="...")

"Что я сегодня делал?"
  → get_daily_summary()

"Запомни что я сейчас работаю над проектом X"
  → log_daily_activity("Working on project X", category="work")

"Открой на телефоне статью про Y"
  → phone_open_url("https://example.com/article")
```
