# F.O.L. - Friendly Obedient Listener

FOL is my personal AI assistant for macOS.

I made FOL because I wanted to have my own assistant like JARVIS. It can talk with me, remember things, use tools and help me with my Mac.

## What can FOL do?

- Chat with me
- Talk with voice
- Understand voice commands
- Use tools on my Mac
- Open apps and work with files
- Search the web
- Remember information
- Save memory in Obsidian
- See what is on my screen
- Work with different AI models
- Use Freebuff as the main AI brain
- Use API models as a backup
- Show the assistant in a Dynamic Island style UI
