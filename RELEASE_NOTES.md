# FOL v1.2.0 — Release Notes

> **FOL** — ваш цифровой двойник на MacBook.
> Notch-панель, голос, зрение, живая память (Obsidian), агентный цикл
> с авто-выбором инструментов и автопереключением моделей.
>
> **v1.2.0** — Brain-бэкенды (Codebuff/Freebuff), безопасность (race condition, shell injection, memory leak), 1073+ тестов.

## Системные требования

- **macOS**: 14.0 (Sonoma) или новее
- **Чип**: Apple Silicon (M1+) — рекомендуется
- **RAM**: 8GB+
- **Python**: 3.9+ (рекомендуется 3.11)

## Что в v1.0.0

- 🧠 **Агентный цикл** — 6 агентов (General / Architect / Coder / Reviewer / Researcher / Memory), билингвальный роутер (RU+EN, typo-tolerant), двухэтапный выбор инструментов (5–12 вместо 50)
- 🛡️ **Loop guard** — защита от зацикливания агента (N одинаковых вызовов подряд → прерывание)
- 🔄 **Автопереключение моделей** — `LLM_FALLBACK_MODELS`: если основная модель недоступна (квота, аутэдж), ассистент мгновенно переходит на запасную; модели без ключа пропускаются
- 🖥️ **Desktop tools** — открыть/закрыть приложения, drag, буфер обмена, уведомления, скриншоты, клики/горячие клавиши
- 🌐 **Браузер** — Chrome (`browser_*`) и Safari (`safari_*`), синк cookies из профиля Chrome (с подтверждением пользователя)
- ✉️ **Productivity** — Gmail (письма, черновики, сводки, контакты), Google Calendar (события), Docs, веб-поиск (Tavily)
- 🧠 **Живая память** — Obsidian vault + эпизодическая память + ежедневные заметки + профиль пользователя
- 🎙️ **Голос** — запись через Notch UI, речь JARVIS (TTS), мгновенное прерывание речи при вводе
- 📊 **SSE-чат** — стриминг токенов в реальном времени (macOS + web), tool-call пилюли, состояния thinking/working/complete
- 🛡️ **Безопасность** — `.env` не отслеживается Git, подтверждение опасных действий (`render_confirm_action`), карточки планов (`render_task_approval`)

## Установка

```bash
# 1. Склонируйте и настройте
git clone <repo-url> fol-app
cd fol-app
cp .env.template .env      # укажите LLM_MODEL / ключи (см. README)
pip install -r requirements.txt

# 2. Запустите
./run_all.sh               # все сервисы
./run_all.sh swift         # только SwiftUI приложение
```

Или установите из `.pkg` (см. `build-pkg.sh` / `build-app.sh`).

## Известные ограничения

- Голос/браузер/почта требуют живого окружения (mic, Chrome, Google OAuth) — см. чек-лист
- Unsigned .app требует `xattr -cr` при первом запуске
- Абсолютные пути в репозитории удалены — скрипты теперь резолвят корень проекта сами
