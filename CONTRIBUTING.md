# Contributing to FOL

Спасибо, что хотите помочь! Проект в стадии **v1.0-beta** — приоритет за
исправлением ошибок и обратной связью, а не за новыми функциями.

## Как сообщить о баге

1. Проверьте, нет ли уже такого issue.
2. Опишите: ожидаемое поведение, фактическое, шаги воспроизведения, вывод
   логов `orchestrator` / `agent-server`.
3. Укажите модель (`LLM_MODEL`), версию macOS и способ запуска
   (`./run_all.sh` или `.pkg`).

## Как предложить фичу

Откройте issue с тегом `feature-request`. Крупные идеи из `ROADMAP.md`
обсуждаем до реализации — стабильная ветка не раздувается фичами.

## Pull Request

1. Форкните репозиторий, создайте ветку от `v1.0.0`.
2. Вносите изменения. Новый функционал — вместе с тестами.
3. Убедитесь, что тесты проходят: `python3 -m pytest tests/ -q`.
4. Опишите изменения в `CHANGELOG.md` (секция Unreleased).
5. Откройте PR: что меняет, как проверить, скриншоты при изменениях UI.

## Конвенции

- Python 3.9+ с аннотациями типов; SwiftUI для macOS-приложения.
- Коммиты на русском или английском, в едином стиле с историей проекта.
- Не коммитьте секреты: `.env` и API-ключи в репозиторий не попадают
  (`.env` в `.gitignore`).
