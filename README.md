# FOL - Your Smart Helper for Mac

> **v1.3.0** - Free AI brain, API key rotation, Russian + English, Obsidian memory and 1073+ tests.

FOL is my personal AI assistant for Mac.

I made FOL because I wanted to build my own assistant like JARVIS.

FOL can chat with me, use my Mac, open apps, work with files, see my screen and remember useful information.

It works in **Russian and English**.

---

## What Can FOL Do?

| Feature | What it does |
|---|---|
| **Chat** | Talk with FOL and get answers |
| **Voice** | Speak to FOL with your microphone |
| **Screen** | FOL can take screenshots and understand the screen |
| **Apps** | Open and control Mac apps |
| **Browser** | Open websites, click and scroll |
| **Files** | Find, read and work with files |
| **Memory** | Remember useful information |
| **Obsidian** | Save long-term memory in Obsidian |
| **Agents** | Different agents help with different tasks |
| **Safety** | Important actions need your permission |
| **Languages** | Russian and English |
| **Typo Fix** | FOL can understand some typing mistakes |
